# Приложение Global Tech Tour (Expo)

Шаг 1 из [`docs/architecture.md`](../docs/architecture.md): экраны делегата, координатора и агента на тестовой поездке «Новый ритейл
Китая» (9–14 ноября, участники вымышленные) и открытый каталог 76 программ с сайта. Одно приложение для iPhone, Android
и веб-версии: React Native + Expo SDK 57, навигация — Expo Router (`src/app/`).

## Как открыть на телефоне

1. Один раз: аккаунт на [expo.dev](https://expo.dev/signup) → Settings → Access tokens → Create token;
   в GitHub: Settings → Secrets and variables → Actions → New repository secret `EXPO_TOKEN`.
2. Каждый пуш в `mobile/` публикует обновление (Actions → «Приложение — Expo Go»), в сводке прогона — QR-код.
3. На телефоне: Expo Go из App Store или Google Play, вход тем же аккаунтом Expo, QR-код камерой.

Expo Go открывает только проекты своей версии SDK. Сообщение «Project is incompatible with this version of Expo Go»
значит, что проект новее Expo Go в магазине: SDK проекта держим равным версии Expo Go в App Store (сейчас 57;
проверка — `curl -s 'https://itunes.apple.com/lookup?id=982107779&country=ru'`, поле `version`).

## Команды (из папки `mobile/`)

| Команда | Что делает |
| --- | --- |
| `npm install` | зависимости |
| `npx expo install <пакет>` | добавить пакет — только так, версия подбирается под SDK |
| `npm run typecheck` | проверка типов |
| `npm run export:web` | веб-сборка в `dist/` (проверка, что всё собирается) |
| `npm run sync-catalog` | обновить каталог из клона `Ostap-87/SINOTECH` (по умолчанию `../../sinotech`) |
| `npm run splash` | пересобрать 3D-заставку стартового экрана: `splash/scene.js` → `src/splash/splash-html.ts` (одна страница с three и шрифтом букв, без интернета) |
| `npx expo start` | разработка: QR для Expo Go в той же сети |

Перед пушем: `npm run typecheck` и `npm run export:web` — то же проверяет GitHub Actions «Проверки».

## Что где

- `src/app/` — экраны (каждый файл — маршрут): `index` — вход, `trip/` — вкладки делегата
  (Сегодня, План, Материалы, Люди, Поездка), `catalog/` — программы, `hotel/`, `meal/`, `culture/` — карточки,
  `contacts`, `driver` («Показать водителю»), `profile` («Мой профиль»: питание — несколько вариантов, аллергия — на что
  именно, номер, здоровье, языки, интересы; первый раз — анкета из 4 шагов), `waiter` (карточка для официанта по-китайски).
- Координатор (вход «Войти как координатор», с 16.10.2026): `coord/` — вкладки «Пульт» (цифры дня, сбор группы, переезды,
  «Требует внимания»), «Визиты», «Группа» (люди, питание, расселение), «Объявление»; `person/[id]` — профиль участника;
  `leg` — «Выехали / Прибыли» с поправкой ±1–5 мин, `legs` — журнал переездов, `food-summary` — сводка ресторану
  на китайском без имён, `rooming` — список для отеля латиницей. «Как делегат» открывает вкладки делегата, назад — кнопка
  «Пульт координатора». Профиль, анкета и «Я в автобусе» Анны сразу видны координатору — одно состояние на обе роли.
  `coord/leads` — заявки агентов и с сайта и запросы на расчёт; `view-as` — «Смотреть как…» (делегат, агент, компания).
- Агент (вход «Агент», с 17.10.2026): `agent/` — вкладки «Каталог», «Даты» (выезды и места), «Расчёт» (конструктор ТЗ),
  «Заявки», «Материалы»; `agent-tour/[id]` — карточка программы с выездами и условиями для агента (поля пустые),
  `agent-apply` — заявка на места, `calc/[id]` — ТЗ на расчёт (у координатора — «Взять в расчёт», «Отправить расчёт»).
  Агент видит только свои заявки; подтверждённая координатором заявка занимает места в выезде.
- С 17.10.2026 у делегата: `translator` (переводчик), `guide` (радиогид, включает координатор на «Пульте»), `city`
  и `place/[id]` (подборка у отеля, «Иду гулять», адрес и такси), `followup` («Хочу продолжить»); «Поездка» → «В поездке»
  и «После» (отзыв, оценка визита). У координатора — `visit/[id]` (визит компании: что она видит, перенос времени,
  материалы, QR-код приглашения). Данные этих экранов — `src/data/extras.ts`.
- `src/data/profile.ts` — варианты питания и аллергенов (русский и китайский), карточка для официанта.
- `src/data/agent.ts` — выезды и места, заявки и запросы на расчёт (пример), справочники конструктора расчёта.
- `src/data/group.ts` — группа глазами координатора: профили остальных делегатов, этапы анкеты, переезды дня, визиты, шаблоны объявлений.
- `src/data/catalog.json` — каталог (пишет `tools/sync-catalog.mjs`, цен нет; у каждой программы — дни с временем визитов,
  компаниями и переездами), `companies.json` — компании программ со справкой с сайта; `trip-base.ts` и `trip.ts` — подробное
  демо «Новый ритейл Китая» из прототипа, `demo-trip.ts` — поездка из любой программы сайта, `active.ts` — какая открыта;
  на шаге 2 их заменит сервер.
- `src/ui/` — тема (`theme.ts`: синий `#1a73e8`, Inter, Sofia Sans Extra Condensed), иконки как в прототипе, общие элементы.
- `src/state/` — состояние делегата (`trip.tsx`), координатора (`coord.tsx`) и агента с заявками (`agent.tsx`) в памяти (шаг 1),
  всплывающие сообщения.

Expo меняется от версии к версии: перед работой с API смотрите документацию своей версии
(`https://docs.expo.dev/versions/v57.0.0/`, указатель — `https://docs.expo.dev/llms.txt`), а не память.

## Стартовый экран — 3D-заставка (вариант B, 17.10.2026)

Светлый глобус из точек, маршруты из Москвы в 9 стран со счётчиком, затем точки слетаются в объёмные буквы GTT
из глянцевых шариков. Сцена — `splash/scene.js` (та же, что на вкладке B в `design/start-screen/index.html`),
показывается в `react-native-webview` (`src/ui/Splash3D.tsx`, в вебе — фрейм `Splash3D.web.tsx`); текст и кнопки —
обычные элементы приложения поверх. Касание пропускает анимацию; при повторном входе за запуск и при «Уменьшить движение»
сразу готовые буквы; без WebGL — просто надпись GTT. Правишь сцену — `npm run splash` и коммит обоих файлов.

- **Заметки к визиту** — визит в «Плане» открывает карточку компании (`src/app/company/[id].tsx`): текст, голос (expo-audio),

  разбор и перевод (`src/data/card.ts`: имя — пиньинем, должность и компания — словарём деловых слов). Поля можно поправить.
- **Визитница и снимки визиток** (21.10.2026) — снимок хранится в `BizCard.photo`, миниатюра — `CardThumb` (`src/ui/card-ui.tsx`);

  визиток — в таблице контактов (до 30 штук).
- **Итоги поездки — PDF** — `src/app/report.tsx` + `src/data/report.ts` (expo-print, expo-sharing): компании, заметки, фото,

- **Приложения для Китая** (21.10.2026) — `src/data/china-apps.ts` (Alipay, WeChat, Amap, DiDi, Trip.com, Meituan, Dianping,

## Майндмэп дня и поездки (20.10.2026)

- **Экран** — `src/app/mindmap.tsx` (`/mindmap?day=1` — день, `?day=trip` — вся поездка): карта, «Главное», «Вехи и
  договорённости», «Сохранить майндмэп PDF» (альбомный лист). «Вся карта» — обзор, нажатие увеличивает это место
  («Крупно», листается); на iPhone карту можно увеличить двумя пальцами. Входы: карточка визита, «Итоги поездки»,
  «Поездка → В поездке / После», радиогид.
- **Темы** — `src/data/themes.ts`: словарь деловых тем (логистика, роботы, данные и ИИ, онлайн + офлайн, собственные марки,
  свежие продукты, цены, маркетинг, оплата, поставщики, формат магазина) и слова договорённостей («договорились», «пришлют»,
  «следующий шаг»…). В JS `\w` не видит кириллицу — окончания пишем `[а-яё]*`. У заметки темы можно поправить
  («Изменить темы» в `src/ui/notes-ui.tsx`) — тогда в заметке хранятся `tags` и `deal`.
- **Карта** — `src/data/mindmap.ts`: `dayTree`, `tripTree` строят дерево `MindTree`, `mindSvg` рисует двустороннюю карту
  (SVG, ширина 1000), `tripSummary` — главное за день или поездку. На шаге 2 сервер с ИИ будет отдавать `MindTree` того же вида.
- **Пример** — `src/data/mind-sample.ts`: заметки вымышленного делегата, пока своих нет (переключатель «Мои заметки / Пример»).
- **Рассказ гида** — в «Слушать гида» субтитры сохраняются в заметки текущего визита (`kind: 'guide'`) и попадают в карту.
- **Итоги поездки — PDF** теперь: главные темы и вехи → карта поездки → по дням карта дня и визиты.
- **Расшифровка экскурсии и «Коротко»** (21.10.2026) — `src/app/transcript.tsx`: текст из стороннего приложения переводчика
  (буфер обмена, expo-clipboard, или вручную) сохраняется заметкой `kind: 'guide'` с подписью «Расшифровка экскурсии».
  `src/data/summary.ts` — бесплатное саммари на телефоне: `keyPoints` выбирает главные фразы (темы, договорённости, цифры;
  служебные фразы гида — нет). Длинные заметки в списке и в PDF показываются как «Коротко», полный текст — по нажатию.

## Языки и тема (21.10.2026)

- **Языки** — `src/i18n/`: русский (ключ), английский, китайский, казахский, арабский, хинди. В коде фраза пишется
  по-русски и оборачивается: `__('Создать кабинет')`, с подстановкой — `__('Шаг {a} из {b}', { a, b })`. Словари —
  `src/i18n/<язык>.json` (ключ — русская фраза). Нет перевода — показывается русская фраза.
- Новые фразы: обернуть в `__()`, затем `node tools/i18n-keys.mjs` (сводка), `--missing en` (чего нет, JSON-ом),
  `--prune` (убрать фразы, которых больше нет в коде). Окончания под род и падеж не склеивать из кусков — целые фразы
  («Ссылка скопирована», «Текст скопирован»), иначе перевод не собрать.
- Язык выбирают при первом запуске (`src/ui/LanguageGate.tsx`) и в «Язык и тема» (`/settings`); смена перезапускает
  приложение. Арабский — справа налево (в браузере `dir="rtl"`, на телефоне `I18nManager.forceRTL`). Даты — `dayLabel`,
  `rangeLabel` (Intl; для казахского, если движок его не знает, — свои названия месяцев).
- **Тема** — `src/ui/theme.ts`: светлая и тёмная палитры (`LIGHT_C`, `DARK_C`), выбор «как в системе / светлая / тёмная»
  читается при запуске (`src/ui/prefs.ts`: в браузере `localStorage gtt:pref:theme`, на телефоне файл в папке приложения),
  смена перезапускает приложение. Цвета — только из `C`/`SH`: белые плашки — `C.surface`, объявления — `C.warnCard`.
- Лендинг (`public/landing/index.html`) читает и пишет те же `gtt:pref:lang` и `gtt:pref:theme`: язык и тема, выбранные
  на лендинге, переходят в кабинет.
