# GTT Platform — white label для организаторов поездок

Платформа на основе приложения Global Tech Tour ([Ostap-87/GTT-APP](https://github.com/Ostap-87/GTT-APP)): организатор,
купивший подписку, сам собирает приложение для своих участников — логотип, название, цвет, координатор, экран «Сегодня»
из блоков, плитки и вкладки — и раздаёт код приглашения. Подробности и правила — [`CLAUDE.md`](CLAUDE.md),
рынки и модель — [`docs/market-research.md`](docs/market-research.md).

Обновления общего приложения приходят из GTT-APP: `git fetch https://github.com/Ostap-87/GTT-APP.git main && git merge FETCH_HEAD`.

# Global Tech Tour — приложение

Мобильное приложение (iOS и Android) и веб-панель для бизнес-экспедиций Global Tech Tour
([globaltechtour.ru](https://globaltechtour.ru)): одна поездка — три роли, плюс кабинет агентов и турагентств.

| Роль | Где работает | Что делает |
| --- | --- | --- |
| Делегат | Приложение на телефоне | Программа по дням, «Сегодня», материалы и заметки, люди группы, подготовка и итоги поездки |
| Координатор | Приложение и панель на компьютере | Собирает поездку, согласует визиты, ведёт группу; видит и меняет всё, смотрит глазами делегата и компании |
| Принимающая сторона | Ссылка в WeChat или браузере, китайский и английский | Подтверждает визит, видит гостей и их вопросы, загружает материалы, получает запросы после визита |

| Агент | Приложение и кабинет в браузере | Каталог программ по странам и датам, заявки на места и запросы на расчёт за своих клиентов |

**Статус (16.10.2026):**
- приложение — архитектура и экраны утверждены; идёт шаг 1: [`mobile/`](mobile/README.md) — экраны делегата и каталог
  на Expo, открываются в Expo Go;
- мини-программа WeChat для принимающей стороны — код и сервер готовы, ждут аккаунта мини-программы
  ([чек-лист](docs/wechat-mini-program.md#чек-лист-что-нужно-от-вас)).

Репозиторий публичный: секретов и настоящих персональных данных в нём нет, только вымышленные демо-данные.
